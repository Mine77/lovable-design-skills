# Curated palette presets

The full preset library available when asking the user to pick a color
direction. Each preset is a 4-stop palette expressed as hex values, plus a
one-line description of the vibe and the domains it suits.

When asking the user to choose a palette, render these as **swatch groups**
(four colored squares per option), 4 options per question. Pick presets that
fit the project domain — a travel blog should get ocean/nature palettes,
not corporate; a law firm should get `navy-trust` or `noir-gold`, not
`neon-mint`.

You may also create custom palettes with 4 hex values when none of the
presets fit. Custom palettes should still follow the "anchor + secondary +
neutral + accent" rhythm visible in the presets below.
